# E-Book Interactivo: Visión por Computadora, RA e IA

Proyecto final de e-book interactivo que integra contenidos académicos de **Visión por Computadora**, experiencias de **Realidad Aumentada (RA)** y una demostración práctica de **Inteligencia Artificial**.

## Autoras
- Paola Romina Meza López — Grupo A2
- Fernanda Monterubio Negrete — Grupo A2

## Contenido y estructura
- `index.html`: Página principal de navegación del e-book.
- `secciones/`: Páginas individuales de Introducción y Unidades 1 a 4.
- `assets/`: Recursos visuales (`imagenes_opencv/`, `diagramas/`, `ra_assets/`).
- `demo_ia/`: Demostración aplicada de detección/clasificación y asistente de preguntas y respuestas.
- `referencias/bibliografia.md`: Fuentes bibliográficas en formato APA 7.

## Herramientas utilizadas
- **Publicación:** GitHub Pages (alternativas contempladas: GitBook, Book Creator, Quarto).
- **Producción de contenido:** Google Docs, Canva, Python (OpenCV y Matplotlib), Excalidraw / draw.io y Zotero.
- **Realidad Aumentada (RA):** AR.js (WebAR), Adobe Aero y Assemblr Studio.
